Le projet est une application mobile unique divisee en 3 modules independants : — Module Professeur — Module Etudiant ´ — Module Administration


##  Comment lancer le projet sur votre machine
1. **Cloner le projet** :
   ```bash
   git clone https://github.com/ZakariaAyad1/mobileEnsaTetouan.git
   ```
2. **Ouvrir avec Android Studio** :
   - Choisissez "Open" et sélectionnez le dossier racine du projet.
   - Attendez que **Gradle** termine la synchronisation (cela peut prendre quelques minutes au premier lancement).
3. **Configuration du SDK** :
   - Assurez-vous d'avoir installé le **SDK 36** (ou le plus récent disponible).
   - Le projet utilise **Java 11** (vérifiez dans *File > Settings > Build, Execution, Deployment > Build Tools > Gradle > Gradle JDK*).
4. **Lancer l'Émulateur** :
   - Utilisez un émulateur avec au moins **Android 7.0 (API 24)**.
   - Cliquez sur le bouton "Run" (flèche verte) pour installer et lancer l'application.
